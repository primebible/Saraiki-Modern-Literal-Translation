# Saraiki Modern Literal Translation (SMLT)

The **first freely available Old Testament translation in the Saraiki language** — a modern, literal, verse-by-verse translation released into the public domain.

Saraiki is spoken by tens of millions of people, primarily in southern Punjab, Pakistan, yet has had little to no Scripture available online. This project aims to change that, one chapter at a time.

## Project status

Translation is in progress. The book of **Genesis** is currently being translated and published chapter by chapter.

| Book | Status |
| --- | --- |
| Genesis | In progress (27+ chapters published) |
| Remaining Old Testament | Planned |

## How it is organized

Each book has its own folder, and every chapter is stored as a separate `.yaml` file (for example, `Genesis/1.yaml`). Each file follows a simple, machine-readable structure:

```yaml
book: "..."
chapter: 1
verses:
  - verse: 1
    text: "..."
```

This format keeps the text easy to read, easy to proofread, and easy to reuse in apps, websites, and other tools.

## Contributing

**We are looking for volunteer Saraiki and English speakers** to help translate, review, and proofread the text.

You can help by:

- Translating new chapters and books
- Reviewing existing translations for accuracy and natural wording
- Proofreading spelling, grammar, and formatting
- Sharing the project with Saraiki-speaking communities

To get started, open an [issue](../../issues) to introduce yourself or propose changes, or submit a pull request with your contribution.
